# Project preferences

- Keep design skill installation lightweight. The initial setup contains the design-agent-skills Picks pointers and catalogue guides only.
- Before following a pointer to install an upstream skill, inspect its size and dependencies. Prefer instruction-only files and existing installed capabilities. Ask before adding substantial runtimes, browser downloads, model weights, or broad dependency bundles.
- Prefer existing Figma, presentation, document, and Remotion skills where they already cover the task.
- Open browser pages in a Codex browser panel placed on the right whenever supported.
