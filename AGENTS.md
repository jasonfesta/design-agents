## Craft foundation

Use the installed Emil Kowalski suite as attributed craft guidance. The [router](.agents/skills/emilkowalski-skill/SKILL.md) selects the relevant full skill; read it and required references before applying it. The [craft brief](resources/agents/craft-foundation.md#installed-craft-foundation) maps the suite. Preserve the [source snapshot and license](resources/history/sources/emilkowalski-skills/README.md).

For UI work, start with `emil-design-eng`. For motion, use `animate` or `animate-expo` as appropriate; decide whether motion earns its place, keep frequent/keyboard actions immediate, extend existing tokens, and support interruption. Include reduced motion, keyboard access, and capability-gated hover. Use `mobile-native` for mobile web issues, `apple-design` for physical interactions, and `animation-performance` for measured frame-budget issues. Prefer transforms and opacity; verify version-dependent APIs in the actual stack.

Use `prototype` for requested alternatives, `break-ui` for requested stress testing, and the review/audit skills for those tasks. Keep test surfaces out of production. Follow existing authorization for implementation and fixes. Jason's instructions, the product's design system, accessibility needs, and local design decisions take precedence over upstream stylistic defaults. Do not load all skills or turn a scoped task into an unrequested audit. Prefer existing Figma, document, presentation, and Remotion capabilities when they cover the output.
