## Visual taste still being established

Jason requires defining taste for each branch from research before personal recommendations, and telling the user upfront when that research is missing. Follow [TASTE.md](../../resources/guides/workflows/taste.md) and [COVERAGE.md](COVERAGE.md). The design types are **apps, websites, and games**. Each contains **device type → viewport size → category → subcategory → style**. Apps now use product categories followed by the existing interface families. Websites retain site purposes and games retain genres, each with an interface-family layer. Website/game family names are proposals. Exact screen labels, components, and states remain metadata; styles and personal branch taste remain unresolved. Jigs is retired as a design type and retained under Resources for interactive experiments. Approval of the structure does not approve a style.

The existing [catalogue](../../resources/sources/reviewed.md) records Jason's endorsement of Reelfolio, Inspora, 60fps, Mobbin, Land-book, Refero, Brand Guidelines, and Backgrounds Supply. These are useful research sources. They do not by themselves identify a universal typeface, palette, density, material, or motion treatment.

The [main brief](../../resources/agents/craft-foundation.md) interprets the supplied collection as interest in tactile controls, glass, shaders, expressive motion, and implementation-ready references. Retain that as exploration context. Do not apply those qualities to every design as confirmed preferences.
