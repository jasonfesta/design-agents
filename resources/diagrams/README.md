Each image is a direct, cropped screenshot of its rendered code block or table on GitHub. The browser used GitHub’s dark theme through its color-scheme preference. No text was re-typeset, no synthetic terminal frame was added, and no image-generation tool was used. Full-height captures retain the complete nomenclature trees.
