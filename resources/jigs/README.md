For an actual jig, record the question, reference, adjustable controls, fixed constraints, code/values, and saved result. Keep it with the design branch it supports and link it from the master list. The shared jig now has reusable React source and a local shader test route; use its linked run instructions. Jigs remain a resource type, not a fourth top-level design type.
