# Skill resources

```text
resources / skills
scope     installed instructions and catalogue pointers
runtime   ../.agents/skills/ (from the kit root)
```

The callable skill files stay in the IDE-compatible hidden `.agents/skills/` folder. This list makes them discoverable from Resources. A pointer is a reference, not a complete installed skill. Rebuild with `python3 tools/workspace.py catalogue`.

[Recent’s 25 skills](sources/recent-skills/README.md) records each listing’s installed path, current upstream name, dependencies, and source revision. Some packages are routers or need external tools; consult that receipt before use.

Routers select other instructions. Pointers include catalogue stubs and tool entry points; they do not establish tool readiness. Agent Browser’s [bundled core guide](../.agents/skills/agent-browser/upstream-core/SKILL.md) is available for offline reading.
