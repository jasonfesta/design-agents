# Game consumer categories

Layer 4 · Rechecked October 13, 2026

Use these genres as the consumer-category layer beneath every applicable viewport size in **games**. The 17 names below follow the published [Google Play Console Help](https://support.google.com/googleplay/android-developer/answer/9859673?hl=en) list. IDs are local research identifiers, not Google API constants. The `apps/` and `games/` prefixes distinguish category sets; they do not add another tree level.

Every viewport branch can use this full list without copying it. Select a category from the actual product purpose; an available label does not establish a working platform combination or researched taste. Our use outside Google Play is a design-library convention.

Choose a [screen or flow subcategory](subcategories.md) next, then style. Finer subgenres, mechanics, subjects, and functions stay in separate scope fields.
