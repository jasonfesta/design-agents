## Environment setup

Starting-profile copy from [this type's environment](../README.md), October 12, 2026:

- **Starting sizes:** Record the target display, render resolution, layout units, and safe area. A 1920 × 1080 render target is a library proposal, not a universal viewport.
- **Target requirements:** Controller/remote navigation, focus, viewing-distance requirements, HUD scale, and actual platform support.
- **Actual product/profile:** unset; record width × height, units, orientation, platform/runtime version, input, DPR/render scale, safe areas, and source.
- **Support and verification:** unverified until measured and checked for the actual target.
