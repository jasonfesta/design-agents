# Dream

Revisit selected research or designs and leave useful, evidence-backed progress.

1. Identify the requested targets, current revisions, relevant references, Taste guidance, and run limits.
2. For research, identify connections and gaps; label new ideas as hypotheses.
3. For design changes, use the target's approved direction and existing authorization. Preserve a recoverable starting state, content, functionality, and deliberate alternatives.
4. Inspect the result, make supported improvements, and verify changed views and behavior. Refresh before writing when someone else has edited the target.
5. Stop when the scope is complete or the run limit is reached. Save what changed, evidence, unresolved issues, and the next action.

Keep hypotheses separate from confirmed taste. A self-review does not approve a baseline. Preserve independent candidates; do not select a winner unless asked.

Start with an explicit manual task. Scheduled runs require a scheduling request and an established scope; none is configured by reading this file. [Detailed refinement guidance](../shared/workflow/DREAM.md) applies when a design is enrolled. Routine unchanged scheduled runs should stay quiet.
