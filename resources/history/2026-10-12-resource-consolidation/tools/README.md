# Optional local tools

This folder is for local installations. Only this README belongs in the parent GitHub repository; existing tool checkouts and dependencies remain on this computer.

The personal DialKit source and history are preserved in [the source archive](../shared/sources/dialkit-source.zip). Follow [the reuse guide](../shared/docs/SETUP.md#optional-dialkit) when it is needed on another machine. The existing local development guide is `tools/dialkit/PERSONAL.md`.

Historical installation records are in [shared/docs/setup](../shared/docs/setup/LOCAL-INSTALLATIONS.md). Tool source archives and installed instructions are not a running image-to-component workbench.
