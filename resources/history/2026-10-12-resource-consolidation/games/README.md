# games

Create actual work as `games/<viewport>/<category>/<style>/`. Each created layer has one README. Create folders when needed, rather than copying the entire menu into every viewport.

- **Viewports:** mobile, tablet, desktop, tv. Use [the shared profiles](../shared/viewports/README.md) and record the actual dimensions, units, input, and support.
- **Categories:** [17 game genres](../shared/workflow/taxonomy/GAME-GENRES.md).
- **Styles:** [the games vocabulary](../shared/styles/GAMES.md), with [motion](../shared/styles/MOTION.md) described inside the style record.
- **References:** [Resources](../resources/README.md).
- **Preferences:** [Taste memory and coverage](../shared/taste/MEMORY.md); no branch-specific personal style is defined yet.

A branch README records the task, references, supported feedback, current state, and next action. Components, variants, and supporting assets live with the actual style work. Use [the style template](../shared/styles/STYLE-TEMPLATE.md) when useful.

Earlier viewport/category placeholders are preserved in [History](../resources/history/README.md). Their existence did not establish research or compatibility. [Setup](../instructions/SETUP.md) prepares a branch; Atlas classifies, Taste annotates, Dial builds, and Dream revisits it.
