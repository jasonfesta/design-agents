# Resources

All design resources stay together here. Start with [the catalogue](catalogue.md); each resource keeps its source, dates, notes, and review status.

```text
resources/
  catalogue.md       Main resource index
  collections/       DesEngs, Nero, and the reviewed reference guide
  research/          Design, style, motion, and tool research
  history/           Earlier agents, source snapshots, and unused scaffolding
```

| Collection | Open |
| --- | --- |
| Main catalogue | [All recorded resources](catalogue.md) |
| DesEngs | [Resources, websites, image references, and designers](collections/desengs/README.md) |
| Reviewed references | [Resource guide](collections/reviewed.md) |
| Nero | [Original discovery sources](collections/nero.md) and [capture coverage](collections/nero-coverage.md) |
| Design research | [Category, aesthetic, and motion terminology](research/design-taxonomy-research.md); [direction and DialKit research](research/research-library.md) |
| Tool research | [MCP/tool sources](research/tooling/mcp-landscape.md) |
| Past work | [History index](history/README.md) |

Keep one source record and link it wherever relevant. Preserve differing notes, original labels, attribution, and licenses. Collection membership does not mean personally preferred, installed, or fully reviewed.

Copy this folder to carry the Markdown collection independently. Links into `shared/` or `instructions/` are optional context from the full kit; tools and credentials are separate. Original structured source data and code snapshots remain under `shared/sources/` in the full repository.

The five current agent instructions live in `instructions/`. Documents inside History preserve past work and must not override the current setup.
