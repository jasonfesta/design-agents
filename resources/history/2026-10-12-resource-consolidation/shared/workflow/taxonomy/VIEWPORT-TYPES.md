# Viewport types and sizes

Layer 2 is **viewport**. The canonical definitions now live in the [viewport registry](../../viewports/README.md), with separate [Chrome presets](../../viewports/CHROME.md) and [native references](../../viewports/NATIVE.md).

Use mobile, tablet, desktop, tv, or watch where applicable. Apps, websites, and games have their own initial folder menus. Exact sizes, orientation, platform, and input stay in the profile; a category label alone does not establish support.

The older Mobile grouping could include tablets. New work uses a distinct tablet folder; preserve old source scope when mapping earlier records. Page type remains a [detail](PAGE-TYPES.md), outside the four-layer hierarchy.
