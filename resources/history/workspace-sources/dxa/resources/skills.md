## Featured guides

### Impeccable

[Impeccable](https://github.com/pbakaus/impeccable) provides critique and refinement guidance. Preserve the product's existing identity.

### fal

[fal skills](https://github.com/fal-ai-community/skills) support creative media workflows. Provider credentials and usage credits are separate from installing instructions. Follow the current repository, not retired catalogue package paths.

### Remotion

[Remotion skills](https://github.com/remotion-dev/skills) support editable product videos built with React. A rendering project and applicable product license are still required.

### Design Tokens

[Design Tokens](https://github.com/ilikescience/design-tokens-skill) supports token architecture. Check the actual format and build pipeline before changing production tokens.

### UI Craft

[UI Craft](https://github.com/educlopez/ui-craft) covers interface implementation and refinement. Inspect any additional tooling before installation.

### Interaction Design

[Interaction Design](https://github.com/rastian/interaction-design-skills) helps specify flows and states. Validate behavior with task tests and real users.

### Color Expert

[Color Expert](https://github.com/meodai/skill.color-expert) supports palette and color-space reasoning. Check contrast in the implemented interface.

The featured sources were reviewed in the first edition on September 24, 2026; no completed third-party DxA workflow test is claimed. See [credits](credits.md) and the [upstream notice](upstream-license.md).
