## Before using generated assets

Check service access, usage charges, permitted use, source-asset rights, and export formats. An open-source integration does not make a hosted model free. Keep editable source files and avoid presenting generated concept imagery as a photograph of the actual product.

Source-reviewed entries were checked against their primary product pages on September 24, 2026. Prior-research entries come from the local landscape study and need a current capability check before adoption. None has a recorded DxA generation test.
