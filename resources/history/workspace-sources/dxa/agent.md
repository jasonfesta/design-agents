# Agent Instructions

## Workspace structure

- `website/` — Website design and implementation.
- `agents/` — Agent-related files and configuration.
- `README.md` — Project overview.
- `resources/`, `events/`, and `workflows/` — Public resource guide and event material.
- `skills/` — Original, independently installable DxA skills.
- `assets/` — Supplied event artwork and attribution.

## Working preferences

- Keep website files in `website/` and agent-related files in `agents/`.
- Update `README.md` when the project structure or setup changes.
- Open browser pages in a Codex browser panel placed on the right whenever supported.
