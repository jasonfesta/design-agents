# DxA skills

[Home](../README.md) · [Install](../agents/README.md) · [Upstream skills](../resources/skills.md)

Small, original instructions for designers working with assistants. Each skill works independently; start with the one that matches the task.

| Skill | Use |
| --- | --- |
| [dxa-catalogue](dxa-catalogue/SKILL.md) | Choose relevant agents, MCPs, and skills. |
| [design-mcps](design-mcps/SKILL.md) | Select and check a design-tool connection. |
| [figma-code](figma-code/SKILL.md) | Carry existing designs and components into implementation. |
| [generative-media](generative-media/SKILL.md) | Prepare and review creative assets. |
| [product-craft](product-craft/SKILL.md) | Turn a product task into a reviewable prototype. |
| [research-papers](research-papers/SKILL.md) | Translate research into a design decision. |
| [design-review](design-review/SKILL.md) | Find and prioritize concrete interface problems. |

These skills contain guidance, not external tools or accounts. They do not automatically install one another or any upstream package.
