# Generative media

Translate the brief into the required asset: purpose, subject, dimensions, duration when relevant, visual references, and delivery format. Keep the asset tied to the product narrative.

Use available generation capabilities. For [fal](https://github.com/fal-ai-community/skills) or [Remotion](https://github.com/remotion-dev/skills), inspect the current upstream workflow and account or runtime requirements. A skill does not supply generation credits.

Use a small preview to assess direction before committing to expensive batches. Keep reference sources and generation settings with the output. Never invent a successful generation or treat a preview as the final export.

Inspect the result in its intended placement: cropping, text legibility, consistency, motion timing, captions, and reduced-motion alternatives where relevant. Preserve editable sources when supported; describe limits when the result is raster or rendered media only.

Deliver the asset with its format, source notes, and the checks actually performed.
