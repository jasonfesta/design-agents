# Shared design guidance

These records support the three design folders: [apps](../apps/README.md), [websites](../websites/README.md), and [games](../games/README.md). Actual branch research belongs at `<type>/<viewport>/<category>/`; actual style work belongs inside its `<style>/` folder.

| Folder | Ownership |
| --- | --- |
| [agents](agents/design.md) | Detailed design, Taste, and Dream procedures; entry specs live in [instructions](../instructions/README.md) |
| [taste](taste/MEMORY.md) | Global memory, original reactions, archive, coverage, and learning |
| [viewports](viewports/README.md) | Sizes, units, source presets, and applicability |
| [styles](styles/README.md) | Separate proposed vocabularies for apps, websites, and games |
| [workflow](workflow/START.md) | Research, components, DialKit tuning, application, and handoff |
| [Resources](../resources/README.md), outside shared | Portable Markdown design-resource collection |
| sources | Immutable craft snapshots, original structured resource data, and provenance |

A shared list defines vocabulary. It does not populate personal taste or make a component suitable for every branch.
