# Agent instructions

The five agents are **Setup, Atlas, Taste, Dial, and Dream**. Each has its own Markdown specification.

| Agent | Read | Purpose |
| --- | --- | --- |
| Setup | [SETUP.md](SETUP.md) | Recreate the full design environment by type, viewport, category, and style; copy applicable information and prepare the other four agents. |
| Atlas | [ATLAS.md](ATLAS.md) | Map design categories, styles, patterns, terminology, and their relationships. |
| Taste | [TASTE.md](TASTE.md) | Recognize research, annotate references, and maintain scoped preferences. |
| Dial | [DIAL.md](DIAL.md) | Generate editable components, tune them, and save reusable style variants. |
| Dream | [DREAM.md](DREAM.md) | Revisit research and selected work, explore ideas, and refine designs. |

[Resources](../resources/README.md) is a separate folder of portable Markdown design resources. It can be carried into another workspace independently of these instructions.

The environment entry documents are [apps](../apps/README.md), [websites](../websites/README.md), and [games](../games/README.md). Each contains its current menus and defines the information to carry into its viewport, category, and style records.

The specifications define the roles; automated setup, the image-to-component workbench, and scheduled Dream execution still need implementation. Follow the [build plan](PLAN.md) for the implementation sequence and completion checks. Existing [transfer instructions](../docs/SETUP.md) and [workspace checks](../scripts/workspace.py) remain usable.
