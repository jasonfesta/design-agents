# File ownership

Start with [README.md](../../README.md). These are supporting details, not another setup route.

| Location | Owns |
| --- | --- |
| `instructions/` | The five current agents: Setup, Atlas, Taste, Dial, Dream |
| `resources/catalogue.md` and `resources/collections/` | Source records and collection memberships |
| `resources/research/` | General design and tool findings |
| `resources/history/` | Preserved past work, not current instructions |
| `apps/`, `websites/`, `games/` | Actual design work, created as viewport → category → style |
| `shared/styles/`, `shared/viewports/`, `shared/workflow/taxonomy/` | Reusable names and definitions |
| `shared/taste/` | Personal memory, feedback, learning, and coverage |
| `shared/workflow/` | Detailed references used by the five agents |
| `shared/agents/design.md` | Attributed craft foundation and research context |
| `shared/sources/` | Original structured evidence, licensed sources, and DialKit archive |
| `.agents/skills/` | Installed skill guidance; preserved discovery path |
| `shared/docs/` | Maintenance, transfer, and historical setup notes |
| `scripts/workspace.py` | Checks and optional portable export |
| `tools/`, `.tools/` | Optional local installations; excluded from GitHub |
| `.exports/` | Generated snapshots; excluded from GitHub |

Keep one owner for each record. Link shared definitions from a branch instead of duplicating whole menus. Preserve original sources, local edits, and attribution. The current tree has three type entry documents; the earlier 12 viewport and 324 category placeholders live in History. Create a branch only when it has actual research or design work.

[The migration ledger](FOLDER-MIGRATION.md) records previous paths. The [reuse guide](SETUP.md) explains transfer.
