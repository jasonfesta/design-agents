# Chrome Custom device

- Profile ID: `chrome-custom`
- Device-type hint: select the actual device class; record width × height separately.
- Width and height: explicitly chosen CSS pixels, not yet set.
- DPR, input mode, user agent/client hints, orientation, safe areas, and posture: record the selected settings.
- Status: configurable browser profile; no default design size or target support is asserted.

Chrome exposes Mobile (touch), Mobile (no touch), Desktop, and Desktop (touch) interaction/rendering modes. Record the actual choice; a window width alone does not select it. Custom devices can supply names, dimensions, DPR, user agent, type, and client hints. Keep the completed project profile with the direction and pin it for Dream comparisons.
