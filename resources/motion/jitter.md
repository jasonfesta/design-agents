# Jitter

Tool reference · Source text and catalogue metadata reviewed October 12, 2026 · Moving templates not visually evaluated in this pass

[Jitter](https://jitter.video/templates/) is a motion-design tool with templates for text, UI elements, logos, and other outputs. Its [text documentation](https://help.jitter.video/en/articles/6500074-animate-text) separates letter, word, line, and whole-text animation units.

Record the source/template URL, customization, output format, and embedding requirements. Inspect the animation before classifying its effect. Provider template titles remain reference names; use [the motion vocabulary](techniques.md) for normalized techniques. Jitter is an authoring tool, not a single aesthetic.
