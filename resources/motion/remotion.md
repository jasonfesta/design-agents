# Remotion

Tool reference · Source documentation reviewed October 12, 2026 · No runtime tested in this research pass

[Remotion](https://www.remotion.dev/docs/) provides programmatic video creation with React. Its [templates](https://www.remotion.dev/templates) cover captions, code animation, and audio visualization. Its [spring primitive](https://www.remotion.dev/docs/spring) exposes physical parameters.

Record the project/version, selected technique, and rendered-video or player output. A video of an interface does not establish that interface's live interaction behavior. Name the aesthetic and [motion technique](techniques.md) independently of the tool.

The installed Remotion guidance is discovered through `.agents/skills/`; read the relevant local skill before an actual build. This record does not install dependencies or verify a production workflow.
