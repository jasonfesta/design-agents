# Design guides

Use these records for naming, reference research, and the Taste/Dial workflow. The [master list](../README.md) connects them with styles, motion, tools, and source collections.

## Choose the design branch

| Decision | Record |
| --- | --- |
| Apps, websites, or games; then category | [Categories and folder structure](../structure.md) |
| Device type and viewport dimensions | [Viewport profiles](../viewports/README.md) |
| Matching aesthetic | [Styles](../styles/README.md) |

The hierarchy is **type → device type → viewport size → category → subcategory → style**. Create project folders only when work begins. App product categories use the Google Play baseline; interface families sit beneath them. Websites retain site purposes and games retain genres, each with interface subcategories.
