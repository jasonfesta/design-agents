# App onboarding references — Spotted in Prod

User-supplied research · Captured October 12, 2026 · Apps / mobile portrait · Personal style fit unassessed

The [onboarding collection](https://www.spottedinprod.com/tags/flow/onboarding) displayed **93 clips** in its gallery counter. Jason asked to bring these app examples into the learning library, then stopped further collection. This saved batch contains **39 clips across 36 apps**, with 39 source posters and 39 six-frame contact sheets. The batch is a convenience sample, not a representative ranking or complete survey.

The original animations are saved as MP4 video, not converted GIFs. Combined clip duration: **8.5 minutes**. Source videos and posters: **156.1 MiB**. [Dated source inventory](../../../history/sources/spotted-in-prod/onboarding/2026-10-12/README.md) preserves metadata, dimensions, timestamps, original asset URLs, byte counts, and SHA-256 hashes.

## How to read the notes

Each description is based on six evenly spaced frames across the saved clip. Sequence descriptions record visible changes between those frames; they do not establish exact easing, timing, gesture mechanics, implementation, accessibility, or every intermediate screen. Open the MP4 when those details matter. Learning candidates are design interpretations, not Jason’s approved preferences. Source tags are preserved verbatim in each metadata file. All entries are classified as apps as requested; source gameplay tags remain intact.

## Patterns to revisit

- Keep primary controls anchored while the demonstration changes: Revolut, Acme Weather, Tiempo, and Shuffles.
- Show a concrete first result: Art of Flora’s completed image, 2006’s camera, and Blackbird’s reward.
- Explain permissions where their value is visible: Moods Faster, Focus Four, and Alyx.
- Carry the brand into the first task: corner’s interest collage, Tolan’s naming scene, and Ditto’s social content.
- Review accumulated requests separately from visual appeal: ratings, notifications, referral surveys, and paywalls can add setup friction.
