[Fancy Components](https://www.fancycomponents.dev/) provides React, TypeScript, Tailwind CSS, and Motion components. Its [introduction](https://www.fancycomponents.dev/docs/introduction) describes free personal/commercial use. The repository license and rights for individual demo assets have not been independently checked. The official [component index](https://www.fancycomponents.dev/llms.txt) links the [source repository](https://github.com/danielpetho/fancy).

The [primary source records](source-records.md) feed the single [master catalogue](../README.md); this file owns the collection's detail.

## Supplied example

[Marquee Along SVG Path](https://www.fancycomponents.dev/docs/components/blocks/marquee-along-svg-path) moves HTML elements along an SVG path using CSS `offsetPath`/`offsetDistance` and Motion. Its documentation covers speed, direction, repetition, hover slowdown, scroll velocity, drag, easing, and viewport scaling.

**Proposed Dial use:** a reusable motion component with controls for the selected path, speed, direction, item spacing, and relevant interaction behavior. This is a technique and implementation reference, not a complete aesthetic. Inspect the live behavior and target compatibility before adapting it; provide appropriate reduced-motion and input behavior in the actual build.

**Review scope:** introduction, official index, and marquee documentation were read. The web reader displayed the demo as loading; no animation playback, installation, code execution, or performance measurement was verified. Other entries below are discovery links only. Reference selection does not establish Jason's preference for continuous motion.
