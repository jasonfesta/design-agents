# Style matching

Layer 6 is **style**. [Apps](../apps/styles.md) and [websites](../websites/styles.md) use the adopted Spotted in Prod design-language menu, with type-specific interpretations. [Games](../games/styles.md) retains its art/rendering research terms.

[The style contract](README.md) owns fit, naming, and record rules. The [style template](template.md) is used for an actual style folder. The [earlier vocabulary](../history/style-vocabulary.md) preserves historical IDs and family/treatment definitions.

The primary app/web menu is adopted; extended influences and individual branch matches remain proposals. Each branch stays unfilled until real exploration or evidence supports a match. Run [TASTE.md](../guides/workflows/taste.md) before claiming a style as Jason's preference. A DialKit-tuned component variant belongs to a style through an explicit mapping and verification, as described in [COMPONENTS.md](../guides/workflows/components.md).

## Working style vocabulary

Use the type-specific files linked above. The [preferred-name registry](README.md) separates aesthetic terms and aliases; the [motion vocabulary](../motion/techniques.md) supplies named techniques, timing concepts, and tool distinctions. Store these as fields within the style record. Do not copy every style into every category.
